# Finrod Chen — Logo Pack

## 設計語彙
- Geometrics F 字，serif "Finrod" wordmark
- 主色：ink `#0A0E1A` · paper `#FAFAF7` · electric blue `#0066FF` · coral `#FF6B5C`
- 全 SVG 向量，無損縮放

## 檔案
- `logo-monogram.svg` — 72×72 monogram，favicon/site logo
- `logo-lockup.svg` — 280×72 horizontal lockup（mark + wordmark + 標語）
- `logo-favicon.svg` — 32×32 簡化 monogram
- `logo-og-image.svg` — 1200×630 OG / Twitter card
- `logo-mark-fallback.svg` — `public/favicon.svg` 的 32×32 備援

## 使用情境
- header/footer：monogram 或 lockup
- social preview：og-image
- favicon：32×32 或 72×72
- 印刷：所有檔都是 SVG，無 DPI 問題

## 配色原則
- 深底：mark 直接用
- 淺底：mark 加 invert prop 或包淺底 box
